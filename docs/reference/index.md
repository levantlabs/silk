# circuitsilk API reference

Browse *Packages* below for silk's public API, generated from its docstrings.
For prose and signature tables, see the hand-written
API reference at `docs/api-reference.md`.

The package pages are generated at build time from `scripts/api_surface.yaml`,
which lists the public API to document. Alternate names for the same object
appear under *Aliases* on the exporting package's page. Device and element
classes created from catalogs are covered by the [factory guide](factories.md)
rather than individual class entries.
